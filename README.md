# Galáxia 3D

Sistema Solar e galáxia interativos em 3D, feitos com Three.js. Criado por Dani.

Passe o mouse sobre o Sol, os planetas e a Lua para ver eles reagirem, e clique em um deles para a câmera voar até lá e mostrar as informações.

Para ver, abra o `index.html` no navegador (precisa de internet) ou acesse pelo GitHub Pages: https://carvalhozzl.github.io/galaxia-3d/
